# 📊 AI Resume Builder & Analysis Platform

An intelligent full-stack web application that helps users **create, analyze, and improve resumes using AI-powered insights**.

---

## 🚀 Features

### 🧠 AI Resume Analysis
- Deep resume evaluation using NLP techniques
- Skill extraction and keyword matching
- Suggestions to improve ATS score

### ⚡ Quick AI Check
- Fast feedback for resume quality
- Highlights missing skills and improvements

### 📄 Resume Builder
- Structured sections (Profile, Education, Experience, Projects)
- Clean and intuitive UI for data entry

### 🎯 Template Selection
- Multiple resume templates
- Easy switching between designs

### 📊 Data Visualization & Insights
- Resume strength analysis
- Smart feedback based on content

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux (state management)
- CSS (custom styling)

### Backend
- Node.js
- Express.js

### AI / NLP
- Gemini API (Google AI)
- NLP libraries for resume analysis

# frontend

# frontend

# backend

npm install
### 3️⃣ Setup Environment Variables

Create a .env file in backend:

GEMINI_API_KEY=your_api_key_here
PORT=5000
### 4️⃣ Run the project
# Run backend
cd backend
npm run dev

# Run frontend
cd frontend
npm start
